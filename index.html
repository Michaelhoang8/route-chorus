A model of routing, not a RIP implementation

The model first converges on the intact topology, removes one link, then performs synchronous full-vector exchanges for a single destination. Round zero still contains the pre-failure tables, so a next hop may point across the failed link. Each following round recomputes all choices from the previous round's advertisements.

Metric 16 is the unreachable cap. There are no packet timers, asynchronous delivery, triggered updates, route aging, hold-downs, authentication, or actual network traffic. Poisoned reverse is not a universal loop-prevention guarantee; the loop example shows three-router circular forwarding. Simultaneous route changes can also produce transient two-router loops from earlier advertisements in this model.

Convergence is a conversation, not a command.
